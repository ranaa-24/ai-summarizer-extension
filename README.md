# QuickSummary – Chrome Extension

QuickSummary is a simple and lightweight Chrome extension that uses Google's Gemini API to summarize articles and web content. It's designed to help you save time by giving you short, AI-generated summaries of any webpage with just a click.

---

## Features

- Summarize any webpage instantly
- Uses the Google Gemini API (Gemini 1.5 Pro or Flash)
- Clean and minimal user interface
- Stores your API key securely using Chrome's storage

---

## How to Use This Extension (Locally)

This extension is not yet available on the Chrome Web Store. To use it locally:

### 1. Clone or Download the Repository

Click the "Fork" button or download the ZIP file and extract it to a folder on your computer.

### 2. Enable Developer Mode in Chrome

- Open Chrome and go to `chrome://extensions/`
- Enable "Developer mode" using the toggle switch in the top right corner

### 3. Load the Extension

- Click the "Load unpacked" button
- Select the folder where you extracted or cloned this extension

### 4. Add Your Gemini API Key

- After loading the extension, click on its icon
- Open the settings by clicking the gear icon or using the three-dot menu > Options
- Enter your Gemini API key

You can get a free API key from [Google's MakerSuite](https://makersuite.google.com/app/apikey)

### 5. Start Summarizing

Once your key is saved, visit any article or page you'd like to summarize and run the extension. It will show you a concise summary of the content using AI.

---

## About the API

This extension uses the `gemini-pro` model for more accurate summarization. You are responsible for keeping your API key safe and managing your own usage limits.
